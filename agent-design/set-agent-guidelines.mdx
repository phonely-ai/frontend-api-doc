Agent guidelines define how your AI phone agent behaves, speaks, and reacts during conversations. They act as a persistent system prompt, context that stays active throughout the conversation, regardless of which flow block or sub-flow the agent is in.

## Guideline Sections

Guidelines are organized into **predefined section types** grouped by category. You don't need to use every section — add only the ones that make sense for your agent. Click **Add Section** at the bottom of the sidebar to add a new section.

### Behavior & Goals

Sections that shape how your agent acts during every call.

| Section | Purpose | Example |
| :-- | :-- | :-- |
| **Objective** | The primary goal your agent works toward on every call — like qualifying leads, booking appointments, or collecting information. | _"Qualify the caller and transfer them to a licensed agent."_ |
| **Response Style** | Tone, personality, and how the agent sounds — friendly, professional, concise, etc. | _"Be concise and direct. Match the customer's emotional tone."_ |
| **Never Do** | Hard rules the agent must never break — things it should never say, promise, or do. | _"Never say you can call the person back."_ |

### Knowledge & Responses

Sections that provide information and pre-written answers the agent can draw on.

| Section | Purpose | Example |
| :-- | :-- | :-- |
| **General Info** | Business details the agent can reference anytime — hours, location, services, policies. | _"Business hours: Mon–Fri 9am–5pm..."_ |
| **Rebuttals** | Pre-written responses to common objections to keep the conversation moving. | _"When the caller says 'I need to think about it', respond with..."_ |
| **Out of Scope** | What the agent should do when it doesn't know the answer — transfer, take a message, or redirect. | _"Let the caller know that a team member will follow up with an answer."_ |

### Other

| Section | Purpose | Example |
| :-- | :-- | :-- |
| **Custom** | Create your own guideline section with a custom name for anything that doesn't fit the categories above. You can add multiple custom sections. | _Pricing Rules, Escalation Steps, Regional Policies, etc._ |

### Custom Sections

When you select **Custom** from the Add Section dropdown, you'll be prompted to enter a name for your new section. This lets you create as many purpose-specific sections as you need — for example, "Pricing Rules", "Escalation Steps", or "Regional Policies".

Custom sections can be **renamed** at any time by hovering over the section in the sidebar and clicking the pencil icon.

### Managing Sections

- **Add a section**: Click **Add Section** at the bottom of the sidebar and select a section type from the dropdown.
- **Delete a section**: Hover over a section in the sidebar and click the trash icon. This permanently deletes the section and its content.
- **Rename a custom section**: Hover over a custom section in the sidebar and click the pencil icon to change its name.
- **Switch between sections**: Click any section in the sidebar to view and edit it.

### Editing Content

Each section opens a rich text editor where you can write and format your guidelines using headings, lists, bold, and other standard formatting. Changes **auto-save** as you type — you'll see a "Saving..." indicator at the bottom-right of the editor while a save is in progress, which changes to "Saved" once complete.

The footer also shows who last updated the section and when. When you click **Back to Agent Design**, any pending changes are saved automatically.

## Per-Flow Control

By default, guidelines are included in every flow. However, each flow has an **Include Guidelines** toggle in its flow settings that you can turn off if a specific flow should not use the agent-level guidelines.

This is useful when a flow has specialized instructions that conflict with the general guidelines, or when you want to keep a flow's prompt lean.

## Guidelines vs Knowledge Base

| Feature | Purpose | Use Case |
| :-- | :-- | :-- |
| **Agent Guidelines** | Always-on context that defines tone, behavior, and personality. Injected directly into the system prompt. | Agent's character, rebuttals, restrictions, objectives, and general business info. |
| **Knowledge Base** | Stored documents and pages that the agent searches when asked factual questions. | FAQs, pricing details, technical docs, or detailed product info. |

<Tip>
  Think of Guidelines as the brain of your agent, while the Knowledge Base is its library.
</Tip>
