Voice controls the speech callers hear during phone conversations. The selected voice and its settings belong to the agent and apply across its inbound and outbound flows.

Use [Guidelines](/agent-design/guidelines) to control the agent's personality, tone, and response style. Voice controls how those responses sound when spoken.

## Choose a voice

Open **Agent Design**, then select **Voice**.

1. Play a voice to preview it with the sample text in the test card.
2. Search by voice name or filter the library by language, gender, accent, or other available traits.
3. Select the voice you want the agent to use.

The library's **Language** and **Multi-lingual** filters help you find voices. To change the languages the agent understands and replies in, use [Languages in Voice Settings](#choose-languages-for-your-agent).

The selected voice appears first in the library, followed by featured voices. Use the heart control to save a voice to **Favorites**. Favorites are shared across the agent's organization. Use the **Favorites** filter to show only favorited voices, and **Mine** to show voices owned by you or your organization.

To give a voice owned by you or your organization a clearer label, select **Rename voice** in its row, enter a name, and select **Save**. Changing favorites and renaming voices are unavailable while the agent is read-only.

Choose a voice that remains clear at phone-call audio quality and fits the conversations the agent handles. Accent, pacing, and pronunciation are usually more important than how expressive a voice sounds in a short sample.

## Customize the voice

Use **Voice Settings** to adjust the selected voice. On wider layouts, the settings appear beside the voice library. On narrower layouts, select **Voice Settings** to open the panel. You need edit access to change these settings. Changes save automatically.

| Setting | What it controls |
| :-- | :-- |
| **Speed** | How quickly the agent speaks; range varies by provider |
| **Languages** | Which languages the agent understands and replies in |
| **Background Noise** | Optional office ambience and its volume |
| **Pronunciations** | How Cartesia voices pronounce specific names or terms |

### Choose languages for your agent

To add or change the languages used for transcription and replies, open **Agent Design > Voice > Voice Settings > Languages**. New agents start with English.

1. Open **Languages** and select the languages your callers use.
2. Keep the existing language selected when you want to add another. For example, keep **English** selected and add **Spanish** for an agent that handles both.
3. Review the selected languages and wait for **Saved** before leaving.
4. Use **Web Call** to test recognition and replies in each selected language.

Adding a language does not require changing the **Transcriber** when that language is already available in **Languages**.

What you can choose depends on two things:

- **The transcriber.** Each speech recognition engine supports its own set of languages. Switching engines keeps only the languages the new one accepts.
- **The selected voice.** A voice that speaks one language limits the agent to that language. Choose a Spanish-only voice on an English agent and the agent handles Spanish, not both.

When the voice or transcriber limits the agent to one language, **Languages** offers a single choice. Choosing a single-language voice can remove other selected languages; the voice-switch warning names the language that remains.

After changing a voice or transcriber, return to **Languages** and check the selection again. An engine change can remove unsupported languages without the voice-switch warning. Some transcribers do not offer a language selector; see [Troubleshooting](#troubleshooting).

<Tip>
  Select only the languages your callers actually use. Extra languages give the agent more ways to mishear a caller without improving the conversations you expect.
</Tip>

### Add pronunciations

**Pronunciations** is available for Cartesia voices. Add an entry when the agent needs to say a name, brand, acronym, or specialized term consistently.

Enter the written word and its pronunciation, then play the entry before saving it. Expand **Phonemes** only when the generated pronunciation needs a precise adjustment.

### Configure transcription

Use **Voice Settings > Advanced > Transcription Keywords** when the agent mishears an uncommon name, product term, or identifier. Enter each term and press `Enter` to add it. Keywords help recognition; use **Pronunciations** to change how a supported voice says a word.

To add a transcription language, use [Languages](#choose-languages-for-your-agent).

To change the speech recognition engine, open **Agent Design > Settings > Advanced > Speech & Turn-Taking > Transcriber**. This selects the engine, not the languages.

Keep the default unless a needed language is unavailable or call testing shows that another engine better fits your audio conditions. Changing the engine applies its recommended turn-taking defaults and keeps only compatible languages. Return to **Voice > Voice Settings > Languages** to review the selection, then test with **Web Call**.

## Test the voice

Enter a representative sentence in the test card. Include names, numbers, or specialized terms the agent will commonly say.

1. Preview several voices with the same text so the comparison is meaningful.
2. Select a voice, adjust its settings, and preview it again.
3. Confirm the pronunciation, pace, and background sound before testing the complete agent.
4. Use **Web Call** to hear the voice in a real conversation and check turn-taking, interruptions, and phone-call audio quality.

A voice preview tests synthesized speech, not the complete call experience. Always complete a Web Call before relying on a new voice or major setting change.

## Add or clone a voice

Select **Add or Clone a Voice** when the built-in library does not contain the voice you need.

<AccordionGroup>
  <Accordion title="Add a provider voice">
    Choose **Add a voice**, then select the provider and model. Enter the voice ID from the provider and select its language. Add an optional **Name** to label the voice in your library, or leave it blank to use a name derived from the provider's voice name. Adding the voice also selects it for the current agent, so test it before using the agent for live calls.

    To compare the same provider voice on different models, add it again with the same voice ID and a different model. Each model has its own library entry. Give the entries distinct names so you can tell them apart when choosing a voice. The form prevents adding the same provider voice ID on the same model again.
  </Accordion>
  <Accordion title="Clone a voice">
    Choose **Clone a voice**, then upload or record a clear 1–2 minute sample. Enter a unique name, gender, and language, and confirm that you have permission to clone and use the recording. Compare the generated samples before saving one. The saved voice becomes the current agent's selected voice.

    A cloned voice is private to your organization and available to everyone in it. A Phonely platform administrator can instead make a clone public, which adds it to the voice catalog every account sees. If cloning fails, the form shows the provider's error detail so you can correct the sample or settings and try again.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="A language I need is unavailable">
    Check **Voice > Voice Settings > Languages**, rather than the voice-library filters. A single-language voice limits the agent to one language; select a voice using the library's **Multi-lingual** filter if you need several. If the language is still unavailable, review **Transcriber** under **Agent Design > Settings > Advanced > Speech & Turn-Taking**. After changing the engine, return to **Languages** and review the selection.
  </Accordion>
  <Accordion title="I cannot find or change Languages">
    On a narrower layout, select **Voice Settings** to open the panel. Some transcribers do not offer a language choice, so **Languages** is hidden. If you need another language, review the **Transcriber** under **Agent Design > Settings > Advanced > Speech & Turn-Taking**. If the control is visible but disabled, check that you have edit access to the agent.
  </Accordion>
  <Accordion title="The language list failed to load or a change did not save">
    Use the retry action beside the loading error before changing the voice or transcriber. If a language save fails, Phonely shows an error and restores the previous selection. Resolve the error, retry the change, and confirm **Saved** before testing.
  </Accordion>
  <Accordion title="A word is pronounced incorrectly">
    If the selected voice supports **Pronunciations**, add the word and test a clearer pronunciation. If the setting is unavailable, select a Cartesia voice or another voice that already pronounces the term correctly.
  </Accordion>
  <Accordion title="The voice sounds different during a call">
    Confirm that the intended voice is still selected and rerun the preview after changing Speed, Background Noise, or Pronunciations. Then use Web Call: phone audio, caller interruptions, and the surrounding conversation are not represented by an isolated voice preview.
  </Accordion>
</AccordionGroup>
