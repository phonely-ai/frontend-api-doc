Integrations are provider-connected capabilities such as Google Calendar, Gmail, Slack, Make, and Zapier. Use this section when a task requires an external account or provider-specific setup.

Each integration has one canonical guide covering:

- Available actions and supported execution stages
- Connecting or selecting an account
- Configuring the integration block
- Inputs, variables, and outputs
- Testing and troubleshooting

Provider-neutral capabilities such as Talk, Filter, Transfer Call, API Request, and Code are documented under [Block Reference](/blocks/overview).

<Warning>
  The integration guides in this section are draft scaffolds and must be rebuilt before release.
</Warning>
