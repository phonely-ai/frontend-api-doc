Create a separate agent when you need an independently configurable call experience. Duplicate an agent when an existing setup is the right starting point for another organization or variation.

<Frame>
  ![New Agent window with Create from Scratch and Duplicate options](/assets/create-agent-options.png)
</Frame>

<Note>
  Enterprise workspaces and administrators may also see **From Recordings**. This option accepts a ZIP file of call recordings and uses the resulting transcripts to prepare an initial flow and guidelines. The build runs in the background and should be reviewed before the agent is used with callers.
</Note>

## Create an agent from scratch

<Steps>
  <Step title="Open Create Agent">
    Open the agent switcher in the top app bar and select **Create Agent** at the bottom of the list.
  </Step>
  <Step title="Choose Create from Scratch">
    The **New Agent** window shows the available creation methods. Select **Create from Scratch**.
  </Step>
  <Step title="Enter the agent details">
    Enter a **Name** and select the **Organization** that should own the agent. Agent names can contain up to 50 characters.
  </Step>
  <Step title="Create the agent">
    Select **Create**. Phonely creates the initial agent and opens it for configuration.
  </Step>
</Steps>

After creation, configure the agent's voice, guidelines, knowledge, flows, and call settings for the experience you want to deliver.

## Duplicate an existing agent

<Steps>
  <Step title="Open Create Agent">
    Open the agent switcher in the top app bar and select **Create Agent**.
  </Step>
  <Step title="Choose Duplicate">
    In the **New Agent** window, select **Duplicate**.
  </Step>
  <Step title="Select the source agent">
    Use the **Agent** field to find the agent you want to duplicate. You can search the list by agent name, ID, or phone number.
  </Step>
  <Step title="Choose the destination organization">
    Select the **Organization** that should own the duplicated agent.
  </Step>
  <Step title="Duplicate the agent">
    Select **Duplicate**. Phonely opens the new agent when the operation finishes.
  </Step>
</Steps>

Review the duplicated agent before using it with callers. Confirm its shared instructions, knowledge, flows, integrations, phone configuration, and any organization-specific details rather than assuming the copied setup is ready unchanged.

### What duplication copies

Duplication creates a standalone agent named after the source with **(Copy)** appended. It copies the source agent configuration along with:

- Flows and their published versions
- Knowledge-base websites and documents
- Widgets
- Which copied flow is selected as the default

The assigned business phone number is not copied. A/B test linkage is also removed so the duplicate does not remain attached to the source agent's test case.

Knowledge-base content finishes copying in the background. Review the duplicate after that process completes, especially before testing answers that depend on documents or websites.

## Choose the right starting point

| Starting point | Use it when |
| :-- | :-- |
| **Create from Scratch** | You need a new call experience and want to begin from the initial agent configuration. |
| **Duplicate** | An existing agent is a useful base and you plan to review and adapt the copy. |
