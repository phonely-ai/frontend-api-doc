Instead of switching between docs, videos, and trial-and-error, Ask AI lets you ask questions exactly where you’re working and get answers tailored to your current flow.

On the workflow canvas, you’ll see a floating Ask AI button in the bottom corner, giving you quick access to AI assistance while actively designing workflows.

## Ask AI Modes: Assistant and Test

Ask AI has two dedicated modes at the top of the panel.

### Assistant

The Assistant tab is your all-in-one AI partner for building agents and understanding how they work. You can ask it to design entire agents, modify workflows, or answer questions about both the platform and your specific agent , all in the same conversation.

**Building agents**: Ask the Assistant to create or modify agents and their workflows:

- “Build me a customer support agent that handles returns and exchanges.”
- “Add an escalation path if the order lookup fails.”
- “Set up a post-call email summary for every completed appointment.”

**Getting help**: Ask the Assistant about the platform or your agent’s current behavior:

- “Why is the agent moving on without asking for the user’s phone number?”
- “What languages does the agent understand right now?”
- “What’s the difference between live-call and post-call actions?”
- “How do call outcomes differ from call topics?”

### Test Mode

The Test tab simulates your agent like a real call. You’ll see the agent’s greeting (for example, _“Thank you for calling Phonely! How can I help you today?”_ and can interact as if you’re a caller.

You can:

- Type responses to simulate caller input OR switch to talk to speak to it
- Restart tests instantly
- Observe how prompts, branches, and logic behave in real time

This makes Ask AI a powerful companion to test your agent, helping you debug conversational issues before publishing.

#### Talk-mode test sessions persist while a web call is active

When you start a talk-mode test, Ask AI opens the Test panel and runs a live web call against your agent. While that web call is in progress:

- Closing the side panel or switching to the Assistant tab no longer ends the call. The transcript and call state are preserved.
- Re-opening the Ask AI panel takes you straight back into the Test tab in talk mode for the active call, so you can pick up the conversation where you left off.
- Switching between chat and talk modes from the input bar no longer auto-starts a web call. You have to click **Start Test** to begin a new talk-mode session.
