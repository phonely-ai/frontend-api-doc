Ask AI is an in-context assistant embedded directly into Phonely’s Flow Builder. It helps you design, understand, and test call flows without leaving the canvas, turning natural language prompts into actionable guidance while you build.

Instead of switching between docs, videos, and trial-and-error, Ask AI lets you ask questions exactly where you’re working and get answers tailored to your current flow.

## Where You’ll Find Ask AI

On the flow canvas, you’ll see a floating \*\*Ask AI \*\* button (bottom corner). This is your quick entry point while actively designing workflows.

## Ask AI Modes: Build, Help, and Test

Ask AI adapts based on what you’re trying to do, using three dedicated modes at the top of the panel.

### Build Mode

**Purpose:** Help you design and modify workflows.

When the Build tab is active, Ask AI focuses on _construction and logic_. It understands flows, blocks, and common patterns.

You can ask things like:

- “Build a basic order tracking flow.”
- “What’s the best way to collect an email before an API request?”
- “How do I add escalation if the lookup fails?”

This is especially useful when starting from a blank canvas or when refactoring a complex flow.

### Help Mode

**Purpose:** Explain how Phonely works.

In **Help**, Ask AI behaves like a contextual documentation assistant. It explains features, settings, and concepts in plain language.

Examples:

- “What’s the difference between live-call and post-call actions?”
- “How do call outcomes differ from call topics?”
- “What does Auto-gather actually do?”

This mode is ideal when you’re unsure why something behaves a certain way or want clarity without digging through docs.

### Test Mode

**Purpose:** Simulate and validate behavior.

The Test tab mirrors how your agent speaks during a real call. You’ll see the agent’s greeting (for example, _“Thank you for calling Phonely! How can I help you today?”_) and can interact as if you’re a caller.

You can:

- Type responses to simulate caller input
- Restart tests instantly
- Observe how prompts, branches, and logic behave in real time

This makes Ask AI a powerful companion to Test Your Agent, helping you debug conversational issues before publishing.
