## Purpose

Use this page to map a user task to the correct Phonely frontend route. This is the canonical route map for docs and docs-agent work; do not duplicate route tables in `skill.md` or `.mintlify/Assistant.md`.

All routes below were verified against the Next.js App Router under `app/(main)/(routes)/`.

## Route Selection Rules

- IF the task edits agent design, voice, guidelines, or settings, THEN use `/agent/{agentId}` with the matching agent tab.
- IF the task edits knowledge sources, THEN use `/agent/{agentId}?tab=knowledge-base`.
- IF the task edits workflow logic, THEN use `/agent/{agentId}?tab=workflows`.
- IF the task reviews a call transcript, recording, or highlight, THEN use `/call-history/{agentId}`.
- IF the task analyzes call volume, KPIs, data tables, or performance reports, THEN use `/performance/{agentId}`.
- IF the task investigates call branches or path drop-offs, THEN use `/call-paths/{agentId}`.
- IF the task debugs event-level execution, THEN use `/event/{agentId}`.
- IF the task manages flagged issues, statuses, severities, or review notes, THEN use `/agent-review/{orgId}`.
- IF the task configures outbound dialing, campaigns, or outbound call flows, THEN use `/campaign/{agentId}` or `/campaign/{agentId}/{campaignId}`.
- IF the task asks for current testing guidance, THEN use `/testing/ab-test/{agentId}`.
- IF the task asks about legacy evaluations, THEN use `/testing/evaluation/{agentId}`.
- IF the task manages workspace billing, team, phone numbers, messaging, notifications, agents, or admin settings, THEN use `/settings?tab=...`.
