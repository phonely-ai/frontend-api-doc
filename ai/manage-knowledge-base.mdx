## Open The Knowledge Base

1. Navigate to `/agent/{agentId}?tab=knowledge-base`.
2. Confirm the page shows the current agent's documents, websites, or recordings.

## Add Documents

1. Choose the document upload action.
2. Upload one or more supported files.
3. Wait for ingestion to complete.
4. Confirm each document appears with an active status.

## Add Websites

1. Choose the website action.
2. Enter the website URL.
3. Configure crawl settings if the form requires them.
4. Submit the source.
5. Confirm the website entry appears in the table.

## Review Existing Sources

1. Check whether the source is active.
2. Check the last updated time and updater.
3. Remove stale or invalid sources.

## Remove A Source

1. Find the document or website row.
2. Trigger the delete action.
3. Confirm the row disappears from the table.

## Rules

- ALWAYS use the current `agentId`.
- NEVER assume a source is available until it appears in the table.
- IF a website source is added, THEN confirm the final stored URL matches the intended domain.
