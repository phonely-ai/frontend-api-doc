## Delivery Model

Phonely sends a `POST` request to the configured webhook URL after a call completes.

## Receiver Requirements

- The receiver must accept HTTPS requests.
- The receiver must be ready to parse JSON request bodies.
- The receiver should log failed deliveries for later retry or debugging.

## Setup Procedure

1. Open the target agent.
2. Open `/agent/{agentId}?tab=settings`.
3. Add the webhook URL in the webhook configuration area.
4. Save the configuration.
5. Run a test call and confirm the webhook is received.

## Error Handling

- IF the receiver returns a non-success status code, THEN treat the delivery as failed and inspect the receiver logs.
- IF the webhook endpoint is changed, THEN re-run a test call before using it in production.
