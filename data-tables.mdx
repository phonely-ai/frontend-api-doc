Data Tables lets you build saved, agent-specific tables from call data. Use it when a standard Performance chart does not answer the question you need.

Open [**Performance**](/performance), select **Data Tables**, and choose or create a view.

## Build a view

Each view defines:

| Part | Purpose |
| --- | --- |
| **Group by** | Determines what each row represents, such as a time period or call attribute |
| **Metrics** | Calculates counts, totals, averages, percentages, or other supported formulas |
| **Filters** | Limits which calls contribute to the table |

You can create a view manually or describe the result you want and use AI to generate a starting configuration. Review generated groupings, formulas, and filters before saving the view.

Views can be renamed, duplicated, reordered, and deleted. Use one view for each stable reporting question instead of combining unrelated metrics in one table.

## Use metrics and formulas

The metric editor lists the variables supported by the selected agent and table. These can include general call fields, topics, outcomes, custom call outcomes, and flow blocks.

Select variables from the editor rather than typing their internal form. This keeps formulas aligned with the available data.

<Info>
  A formula describes how to calculate a metric. It does not change any call record or flow behavior.
</Info>

## Inspect the calls behind a value

Select a metric cell to open the calls that contributed to it. Use this drilldown to verify that the grouping, filters, and formula represent the intended population.

If a table looks unexpected:

1. Confirm the date and duration filters.
2. Inspect a cell's underlying calls.
3. Check the grouping and formula variables.
4. Review whether topic, outcome, or block names changed for the agent.

## Keep the view current

Refresh the table to load current results. If the agent's topics, outcomes, or flow structure changes, review views that refer to those values.

Use **Export CSV** when you need the current table outside Phonely. The export reflects the active view and its current scope.
