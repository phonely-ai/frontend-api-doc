An outbound campaign must use a published outbound flow. The flow starts with **Make Call** and controls the conversation, routing, actions, and post-call work for every contact the campaign calls.

## Select or create the flow

In the **Call flow** step, either **Use an existing flow** and pick one of the agent's outbound flows, or **Create a new flow**. Creating one opens the flow editor with Ask AI ready to start building it.

Only outbound flows appear in the selector. An inbound flow cannot be converted into an outbound flow after it is created.

## Configure Make Call

**Make Call** is the trigger for an outbound flow. Configure its greeting and voicemail behavior, then connect the live-call and post-call blocks the campaign needs.

The campaign determines the contact and outbound phone number. The flow determines what the agent says and does after the call begins.

## Map campaign data

The **Variables** step maps campaign source fields to the variables the flow needs. Map a field when the flow needs that value for personalization, routing, or an action. Use **Ignore this variable** to leave a variable unmapped on purpose; it is then left empty on the call.

For example, a source may provide `name`, `appointment_time`, and `account_id`. Once mapped, supported fields in the flow can select those values from **Available Variables**.

If you change the CSV columns, webhook fields, Google Sheets columns, or variables used by the flow, return to the campaign and review the mappings.

## Test before launch

1. Test the outbound flow with representative source values.
2. Publish the flow version you intend the campaign to use.
3. Verify the campaign's field mappings and phone-number routing.
4. Run a controlled campaign call to a number you own.

Confirm the greeting, conversation paths, actions, voicemail behavior, and post-call work before adding production contacts.
