Every outbound campaign calls from numbers in your own Twilio account. In the **Phone numbers** step, add numbers from Twilio and switch on the ones the campaign can call from. Only switched-on numbers dial.

Select **Add numbers from Twilio** to open the picker, which groups available numbers by region. If your Twilio account is not connected yet, an inline connect step links it with your Account SID and Auth Token before you add numbers.

## Choose a routing method

The **Number routing** step appears only when two or more numbers are switched on. It controls which number places each call:

| Method | How Phonely selects a number |
| --- | --- |
| Percent-based routing | Splits calls across your numbers by the percentage you give each one. Switching a number on or off re-splits the share evenly. |
| Location based routing | Calls each person from a number in their state or country, when a matching number is available. |
| Internal routing | Your data names the number to call each person from. |

Location based routing lets you match on **state** or **country**, and falls back to another enabled number when no regional match is available.

## Internal routing: name the number per contact

Choose **Internal routing** when a campaign source field already carries the number to dial from for each person. Point the step at the source field that holds that number.

The named value must match a switched-on number in the campaign; otherwise that contact fails instead of using another number. A contact without a usable value uses the campaign's other enabled numbers.

## Verify the numbers

Before launching the campaign:

1. Confirm that every intended number is switched on.
2. For percent-based routing, review the share given to each number.
3. For location based routing, test a matching contact and a contact that requires the fallback pool.
4. Place a controlled outbound call and verify the number shown to the recipient.
