title: "Upload Contacts By CSV"
description: "Exact procedure for importing outbound campaign contacts from CSV."
---

## Procedure

1. Open `/campaign/{agentId}`.
2. Create or open a campaign.
3. Choose the CSV upload source.
4. Upload the CSV file.
5. Map required columns if the UI requires mapping.
6. Confirm the contact count before launch.

## CSV Rules

- ALWAYS validate the contact file before launch.
- ALWAYS confirm the campaign uses the intended agent and phone number.
- IF required contact columns are missing, THEN correct the CSV before importing.
