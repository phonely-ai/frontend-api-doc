Agent Review is the workspace for triaging and resolving issues that were flagged during call review. It is designed for teams that need to move from "something went wrong" to an organized queue of work.

Open `/agent-review` to jump to the first available organization, or open `/agent-review/{orgId}` directly when you already know which organization you want to review.

## What Agent Review Is For

Use Agent Review to:

- see open review issues grouped by agent
- prioritize issues by status, severity, and tags
- open the full issue detail sheet for transcript and call context
- update issue status as work moves from triage to resolution

## Main Areas Of The Page

### Status Tabs

The top of the page includes these tabs:

- `Open`
- `In Progress`
- `Resolved`
- `Cancelled`
- `All`

### Filters

Use the page filters to narrow the queue by:

- organization
- date range
- severity
- tags

### Issue Groups

Issues are grouped by agent so you can quickly see which agents have the most review work and how many issues are still open.

### Issue Detail Sheet

Selecting an issue opens a detail sheet where you can review the issue context and update it without leaving the page.

## Review Workflow

1. Open `/agent-review` or `/agent-review/{orgId}`.
2. Choose the correct organization.
3. Select the status tab you want to work through.
4. Apply date, severity, or tag filters if needed.
5. Open an issue from the list.
6. Review the transcript, recording, call links, tags, severity, and current status.
7. Update the issue to `In Progress`, `Resolved`, `Cancelled`, or `Open` as appropriate.

## Bulk Actions

If you select multiple issues, Phonely shows a bulk action toolbar. Use it to:

- reopen issues
- mark issues as `In Progress`
- mark issues as `Resolved`
- mark issues as `Cancelled`

## Agent Review vs Other Review Pages

| Page | Use it for |
| --- | --- |
| `Call History` | transcripts, recordings, summaries, and single-call analysis |
| `Call Events` | event-by-event debugging for workflows and integrations |
| `Agent Review` | issue tracking, triage, prioritization, and team follow-up |
