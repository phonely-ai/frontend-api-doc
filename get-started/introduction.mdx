## What is Phonely?

<Frame>
  ![Phonely flow builder with a live call in progress](/assets/phonely-hero.png)
</Frame>

Phonely is a platform for building voice AI agents that handle phone calls. You design conversations visually, connect your tools, and deploy — no code required.

- Make and receive calls on Phonely numbers or your own carrier
- Route, schedule, and escalate to humans based on rules you define
- Connect to calendars, CRMs, and any REST API
- Track calls with analytics, A/B testing, and call path visualization

<Info>
  Want to jump right in? [Get started for free](https://phonely.ai).
</Info>

## Frequently Asked Questions

<Accordion title="Do I need to know how to code?">
  No. The Flow Builder is fully no-code - drag-and-drop blocks with prompts.

  For advanced use cases, you can use custom APIs, webhooks, and cURL imports.
</Accordion>

<Accordion title="Can Phonely integrate with my CRM or scheduling software?">
  Yes. Phonely connects to Google Calendar, HubSpot, Salesforce, Zapier, and any REST API.

  If there’s no native integration, you can import any API from a cURL command using the [API Request block](/blocks/live-call-actions/api-request).
</Accordion>

<Accordion title="How do I train my AI agent?">
  Upload your knowledge base (FAQs, SOPs, or website) and define your call flows. Each flow includes talk blocks, integrations, variables, and post-call actions. Ask AI can help generate prompts and connect APIs.
</Accordion>

<Accordion title="Can Phonely make outbound calls?">
  Yes. Upload a CSV, connect a Google Sheet, or use an API. Outbound campaigns include voicemail detection, retry logic, and DNC compliance tools. See [Outbound Campaigns](/outboundcalling/createaoutboundcallingcampaign).
</Accordion>

<Accordion title="What analytics are available?">
  Call summaries, sentiment analysis, topic clustering, A/B testing results, call path visualization, and performance metrics. See [Analytics](/call-history-ai-analytics/call-history-ai-analytics).
</Accordion>

<Accordion title="Does Phonely support multiple languages?">
  Yes. Configure voices for English, Spanish, French, and many others, including regional accents and custom voice cloning.
</Accordion>

<Accordion title="Is Phonely SOC 2, HIPAA, PCI, or GDPR compliant?">
  Yes. Data is encrypted in transit and at rest. See [Compliance Settings](/agent-design/compliance-settings) for details.
</Accordion>
