Phonely lets you design AI phone agents using visual workflows. Instead of writing scripts, you connect blocks that control what the agent says, what it listens for, what data it collects, and what actions it takes during and after every call.

## Building an AI Agent in Phonely

### Learn the concepts

Phonely combines three core systems that work together in every call.

1. Your agent configuration defines the voice, tone, and knowledge it uses.
2. Your workflow (flow) defines the conversation logic.
3. Your data and integrations turn calls into real business actions.

When a call comes in, Phonely follows your flow in real time, collecting variables, making decisions, calling APIs, transferring calls, scheduling appointments, or taking payments.

## Let's build your agent right now.

Building voice AI agents has never been easier. Get started in just a few simple steps to build the AI that can automate anything, repeatedly, every single time.

### Create and Agent

Agents are the core of your Phonely workspace. Each agent represents a virtual assistant that can manage calls, collect data, and automate workflows using custom call flows, knowledge sources, and integrations.

You can create a new agent from scratch to handle a specific business area or campaign. Navigate to the top of the main menu under the Agent section, click **Create Agent**. In the **New Agent** window, choose **Create**.

<Frame>
  ![How To Create Agent And Duplicate Agent Gi](/assets/how-to-create-agent-and-duplicate-agent.gif)
</Frame>

### Pick a voice

[Choose](/agent-design/voice/voice-selection) from thousands of pre-built voices, import from leading providers, or [clone](/agent-design/voice/clone-voice) a custom voice in minutes to match your brand.

![Manage Your Ai Voices In Phonely Gi](/images/manage-your-ai-voices-in-phonely.gif)

### Add your knowledge

Upload FAQs, SOPs, pricing sheets, and policy documents into the [knowledge base](/agent-knowledge-base/). Phonely uses retrieval-augmented generation (RAG) to answer questions during the call using your actual content.

This allows your agent to respond accurately without hard-coding every answer into the workflow.

![Knowledbase View In Phonely Gi](/images/knowledbase-view-in-phonely.gif)

### Design the Call Flow

Open the workflow builder and begin laying out how the call should work. Flows are visual. Each block represents something the agent does:

<Expandable title="Examples">
  - speak to the caller
  - ask a question
  - collect data
  - check a condition
  - collect payments
  - call an API
  - schedule an appointment
  - transfer to a human
  - end the call
</Expandable>

You connect these blocks to define how the conversation moves forward.

You can also use [Ask AI](/key-concepts/ask-ai/) inside the builder to generate, explain, or improve your flow while you work.

### Capture variables

Use [variables](/key-concepts/variables/) to define what to collect (e.g., name, phone number, DOB). Use [auto-gather](/key-concepts/auto-gather-variables/) to collect data exactly when the block needs it.  When a block needs information (name, order number, email, payment amount), the agent automatically asks the caller, confirms it, and stores it in a variable.

These variables can then be:

- used in logic
- sent to APIs
- inserted into emails
- logged after the call, etc.

You can mark important fields as required, enable confirmation, and spell-back to ensure accuracy.

![Variable configuration panel](/images/vairable-configuration_panel.gif)

### Route, Transfer, and Escalate

Add warm [transfers](/blocks/live-call-actions/new-transfer-call) (with voicemail detection and fallback) or cold transfers.            \
Route by intent, person, or department to keep every call moving toward resolution.

### Integrate actions

Flows can trigger real actions using pre-built integrations. For example, you can:

- Check availability or book meetings in Google Calendar
- Send or receive data via API
- Read or write to Google Sheets
- Create tickets via webhooks
- Take PCI-compliant payments
- Send emails or SMS

All of these use the same variables collected during the call.

### Publish & test

Click **Publish**, choose **Test**, or call your provisioned number to hear your agent live. Iterate fast and deploy instantly.

You do not have to call from the beginning every time you want to test your workflow. You can right-click any block and choose [Test from here](/testing/test-from-a-block/) to simulate a call starting at that point, using dummy values. This makes debugging and iteration extremely fast.

Every publish is versioned so you can safely roll back or compare changes later.

![Test Workflow Publish Save Draft Gi](/images/test-workflow-publish-save-draft.gif)

Once you've built and tested your first agent, you'll start to see how flexible Phonely really is. Every block, variable, and integration can be iterated on in seconds, so you can continuously improve performance and add new capabilities as you scale.

From here, you're ready to explore the deeper concepts that power every Phonely agent: flows, outbound calling, and A/B testing.

## FAQ

<AccordionGroup>
  <Accordion title="How long does it take to build my first agent?">
    Most users build a working voice agent in under **10 minutes** using the Quick Start tutorial.\
    If you’re connecting integrations or APIs, expect another few minutes to authenticate and map variables.
  </Accordion>

  <Accordion title="What if my business uses multiple software tools?">
    You can connect multiple integrations inside a single flow. For example, pull appointment data from Google Calendar, send confirmations via SMS, and log the interaction in HubSpot, all in one call.

    <Tip>
      If you don’t see your integration listed, you can **import any API directly from a cURL command** to make it work instantly.
    </Tip>
  </Accordion>

  <Accordion title="Can I test my agent before deploying it?">
    Yes. Use the **Test** button on the agent design page or call your assigned Phonely number. You can hear the agent in real time, confirm it follows your call flows, and review analytics immediately after.
  </Accordion>

  <Accordion title="What if the AI gets something wrong on a call?">
    Check the **Call History** tab to view transcripts, summaries, and reasoning for every decision the AI made. From there, you can retrain your flow or tweak prompts. Each call is logged with topic, sentiment, and variable data for easy troubleshooting.
  </Accordion>

  <Accordion title="How do I connect my existing phone number?">
    You can forward, port, or provision a new number with Phonely.\
    Most users forward their existing line to their Phonely number during setup to start testing immediately.
  </Accordion>
</AccordionGroup>
