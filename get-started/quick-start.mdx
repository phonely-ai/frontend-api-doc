Every Phonely agent has three parts:

1. **Agent config** — voice, tone, and knowledge base
2. **Workflow** — the conversation logic (built visually with blocks)
3. **Integrations** — APIs, calendars, CRMs, and post-call actions

## Build your agent

### Create an agent

Go to the main menu, click [Create Agent](/key-concepts/create-duplicate-agents), and choose **Create**.

<Frame>
  ![How To Create Agent And Duplicate Agent Gi](/assets/how-to-create-agent-and-duplicate-agent.gif)
</Frame>

### Pick a voice

[Choose a voice](/agent-design/voice/voice-selection) from the library, import from providers like ElevenLabs, or [clone your own](/agent-design/voice/clone-voice).

![Manage Your Ai Voices In Phonely Gi](/images/manage-your-ai-voices-in-phonely.gif)

### Add your knowledge

Upload documents (FAQs, SOPs, pricing) into the [knowledge base](/agent-knowledge-base/). Phonely uses them to answer caller questions without you hardcoding every response.

![Knowledbase View In Phonely Gi](/images/knowledbase-view-in-phonely.gif)

### Design the call flow

Open the [Flow Builder](/key-concepts/flows) and connect blocks: talk, collect data, check conditions, call APIs, transfer, end call. Use [Ask AI](/key-concepts/ask-ai/) to generate or refine blocks as you go.

<img
  src="/assets/ask-ai-example.png"
  alt="Ask Ai Example"
  title="Ask Ai Example"
  style={{ width:"89%" }}
/>

### Capture variables

[Variables](/key-concepts/variables/) store what callers say — name, phone, email, etc. Use [auto-gather](/key-concepts/auto-gather-variables/) so blocks collect data the moment they need it. Variables can be used in logic, APIs, emails, and post-call logging.

![Variable configuration panel](/images/vairable-configuration_panel.gif)

### Route and transfer

Add [warm or cold transfers](/blocks/live-call-actions/new-transfer-call) with voicemail detection and fallback. Route by intent, department, or person.

<img
  src="/assets/cold-and-warm-call-transfers.png"
  alt="Cold And Warm Call Transfers"
  title="Cold And Warm Call Transfers"
  style={{ width:"69%" }}
/>

### Connect integrations

Trigger actions during or after calls: book in Google Calendar, send data via API, write to Google Sheets, take payments, send emails or SMS.

<img
  src="/assets/make-an-api-request-quick-start.png"
  alt="Make An Api Request Quick Start"
  title="Make An Api Request Quick Start"
  style={{ width:"53%" }}
/>

### Publish and test

Click **Publish** to go live, or use **Test** to try your agent first. You can also right-click any block and [Test from here](/testing/test-from-a-block/) to start mid-flow with dummy values.

Every publish is versioned — you can roll back anytime.

![Test Workflow Publish Save Draft Gi](/images/test-workflow-publish-save-draft.gif)
