Open **Settings > Agents** to review the agents in the current organization. The table includes identifying and operational details such as the agent name, phone number, agent ID, monthly call minutes, and last update time. Some columns depend on your access level and table settings.

## Export agent usage

Use **Export Usage** to download usage data for the agents in the table. For interactive charts and filters, use [Usage and Cost](/billing-and-usage/manage-agents-and-usage).

## Delete agents

1. Select the checkbox beside each agent you want to remove.
2. Select **Delete agents** in the selection toolbar.
3. Review the selected agents and confirm **Delete agents**.

<Warning>
  Deleting an agent is permanent. Confirm that you no longer need its configuration or associated resources before continuing.
</Warning>
