This page lists every change to API v1, newest first. It's also where Phonely announces a breaking change to a Beta endpoint, at least 14 days before it happens. See [Versioning and stability](/api-reference/v1/versioning).

<Update label="API v1 release" description="First release">
  API v1 is available. It covers agents and their voice, guidelines, settings, call analysis and blocked numbers; calls with their transcripts, recordings and post-call outcomes; knowledge sources; organizations and usage; and voices.

  The endpoints for an agent's voice, guidelines, settings and call analysis are Beta.

  To move from the legacy API, see [Migrate from the legacy API](/api-reference/v1/migrate-from-legacy).
</Update>
