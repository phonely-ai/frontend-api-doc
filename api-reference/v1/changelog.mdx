This page lists every change to API v1, newest first. It's also where Phonely announces a breaking change to a Beta endpoint, at least 14 days before it happens. See [Versioning and stability](/api-reference/v1/versioning).

<Update label="2026-11-27" description="Organization-wide call counts and links to the web app">
  **Added**

  - `web_url` on agents and calls: the agent's or call's page in the Phonely web app.
  - `GET /v1/calls/counts` without `agent_id` counts the whole organization's calls, including deleted agents' calls. It needs `started_from`, at most 31 days back, and doesn't take `experiment_id` or `analytics_field`. A new `agent` breakdown lists the agents with the most matching calls.

  **Changed**

  - `GET /v1/calls/counts` no longer returns `agent_id`. Read the counted agent from the new `agent` breakdown instead.
</Update>

<Update label="2026-11-25" description="Find an organization, and what each transcript action did">
  **Added**

  - `GET /v1/agents/{id}/organization` and `GET /v1/calls/{id}/organization`: the organization an agent or call belongs to, for when you have its ID but not its organization.
  - Each action in `GET /v1/calls/{id}/transcript` gains `duration_seconds` and an object for its kind of action, such as `http`, `code`, `transfer`, `sms` or `email`, with what it sent and received. Credentials Phonely recognizes are shown as `***`.
</Update>

<Update label="2026-11-18" description="Call counts and search, and knowledge changes">
  **Added**

  - `GET /v1/calls/counts`: how many calls match, in all and by status, type, ended reason, sentiment and outcome. It takes the same filters as `GET /v1/calls`.
  - Filters for `GET /v1/calls`: `customer_phone_number_contains`, `transcript_contains`, `analytics_field` and `experiment_id`. A page of calls can now hold up to 500.
  - Call fields: `is_read`, `user_review`, `failure_reason`, `experiment_ids` and `experiment_arm`, and `warm_transfer_started_at` in the calls list.

  **Removed**

  - Adding website pages to an agent's knowledge (`POST /v1/agents/{id}/knowledge-sources/websites`) and discovering them (`POST /v1/agents/{id}/knowledge-sources/website-map`). Add website pages in the Phonely web app.
</Update>

<Update label="2026-11-11" description="API v1 release">
  API v1 is available. It covers agents and their voice, guidelines, settings, call analysis and blocked numbers, and duplicating an agent; calls with their transcripts, recordings and post-call outcomes; knowledge sources; organizations and usage; and voices.

  The endpoints for an agent's voice, guidelines, settings and call analysis, and for duplicating an agent, are Beta.

  To move from the legacy API, see [Migrate from the legacy API](/api-reference/v1/migrate-from-legacy).
</Update>
