---
title: "List Documents"
description: "List the documents in an agent's knowledge base."
sources:
  - "app/api/agent-documents/route.ts"
last-verified: "2026-10-23"
openapi: "GET /agent-documents"
---

Returns the documents associated with an agent's knowledge base. The API key must belong to the supplied user, and that user must have access to the agent.

For an uploaded file, `fileUrl` is a signed download URL that expires one hour after the request. Download the file within that hour, or list the documents again for a fresh URL; don't store it. `fileUrl` is `null` when the uploaded file no longer exists.

Use the related operations to upload or delete documents. An upload accepts up to 10 PDF, DOCX, or TXT files per request, with a maximum size of 10 MB per file.
