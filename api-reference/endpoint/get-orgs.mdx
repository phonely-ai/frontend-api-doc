---
title: "Get Organizations"
description: "List the organizations assigned to a user."
sources:
  - "app/api/get-orgs/route.ts"
last-verified: "2026-08-10"
openapi: "GET /get-orgs"
---

Returns compact records for the organizations assigned to the supplied user. Each record includes the organization ID and name.

The `X-Authorization` API key must belong to the supplied user ID.
