---
title: "Get Agents"
description: "List basic information for a user's agents."
sources:
  - "app/api/get-agents/route.ts"
last-verified: "2026-08-10"
openapi: "POST /get-agents"
---

Returns compact records for the agents assigned directly to the supplied user. Each record includes the agent's ID, name, owner ID, country, and business phone number when available.

The `X-Authorization` API key must belong to the supplied user ID.
