---
title: "Duplicate Agent"
description: "Create a copy of an agent you can access."
sources:
  - "app/api/duplicate-agent/route.ts"
last-verified: "2026-08-10"
openapi: "POST /duplicate-agent"
---

Creates a new agent from an existing agent's configuration. The API key must belong to the supplied user, and that user must have access to the source agent.

The response identifies the new agent by its `agentId` and includes its name and owning user ID.
