The frontend `GET /api/usage` endpoint is retired. Requests now return `410 Gone`.

View current usage from **Settings > Usage & Cost** in the platform.

### Request

**Method:** `GET`  
**Endpoint:** `/api/usage`  

### Response

The endpoint returns `410 Gone`. Its response body identifies the endpoint as retired, but it is not a replacement usage-data contract. Do not build new integrations against it.

**Status:** `410 Gone`
