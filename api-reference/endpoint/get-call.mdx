---
title: "Get Call"
description: "Return one call belonging to an accessible agent."
sources:
  - "app/api/get-call/route.ts"
last-verified: "2026-08-10"
openapi: "POST /get-call"
---

Returns call details and analysis for the supplied call and agent IDs. The API key must belong to the supplied user, and that user must have access to the agent.

Phonely returns `404` when the call does not exist or does not belong to the specified agent.
