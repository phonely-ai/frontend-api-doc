Call topics allow Phonely to automatically classify conversations based on the caller’s intent. Each topic represents a specific reason for the call, such as booking an appointment, requesting support, or asking for information. This makes it easier to understand what customers are trying to accomplish and how frequently different types of calls occur.

Using multiple call topics provides deeper visibility into your operations. Instead of viewing all calls as a single group, you can see how different call types perform independently. For example, you can measure how many calls result in appointments, how many require transfers, or how many are general inquiries. This helps you identify trends, evaluate agent performance, and understand which types of alls are most common.

Once configured, Phonely automatically detects call topics during conversations and makes them available across analytics, filtering, grouping, and reporting tools.

## How to add a Call Topic

Call topics define the types of conversations your agent handles. These help Phonely identify caller intent and organize analytics around meaningful categories.

1. Go to agent design \> settings from the left sidebar.
3. Go to the call tagging tab
4. Locate the call topics section
5. Click \*\*add topic. \*\*Enter the topic name and the topic description. The description is where you define what happens for the call to be
7. Click **Add**

## How Call Topics Are Detected

During each conversation, Phonely analyzes the caller’s intent and applies relevant topics automatically.

Once the call ends, these topics become part of the call record and appear in:

- Call History
- Performance analytics

## Viewing Call Topics in Call History

The call history and Analytics dashboard provides a centralized view of all calls.

Each call entry includes the duration, call outcome, sentiment, call topic, and timestamp.

To review or edit detected topics:

1. Go to **Analytics**
2. Click **Call History**
3. Click on any call

This opens the **Highlights page**.

![Call Tags Call Stats](/assets/call-tags-call-stats.png)

In the Highlights page, under the **call stats section**.

You can:

- View automatically detected topics
- select relevant topics
- unselect irrelevant topics

## Using Call Topics in the Performance Page

Call Topics become most valuable when used inside the **Performance page**, where they allow you to isolate, compare, and analyze specific types of conversations. Instead of looking at all calls as a single dataset, Call Topics let you break down performance based on why customers are calling.

This enables you to answer important operational questions such as:

- How many callers are booking appointments?
- How many callers are requesting callbacks?
- How often callers request a human representative?
- Which types of calls convert successfully?

The performance page provides two primary ways to use Call Topics:

- **Filtering** - isolate specific conversations
- **Grouping** - compare different types of conversations side-by-side

## Filtering Calls by Topic

Filtering allows you to narrow the performance dashboard to show only calls that match specific topics.

This is useful when you want to analyze a specific type of conversation without distractions from unrelated calls.

For example, you might want to:

- View only calls where an appointment was booked
- Investigate calls where a caller requested a representative
- Review conversations related to callback requests

### How filtering works

When you apply a Call Topic filter, the entire Performance page updates automatically. This includes:

All data shown will reflect only calls that match the selected topic.

1. Go to **Analytics \> Performance**
2. Click the **Filter** button
3. Locate the **Call Topic** section
4. Select one or more topics (for example: _appointment booked_)
5. Click **Apply**

The dashboard immediately updates to reflect only those calls.

### Example use case

If you select the topic **appointment booked**, you can instantly see:

- How many appointments were booked
- When those bookings occurred
- How performance trends over time
- Which calls resulted in bookings

You can also click any data point to open the individual calls and review them in detail.

This makes it easy to audit successful conversations and understand what worked.

## Comparing Topics Using Groups

Filtering shows only one subset of calls. Grouping, on the other hand, allows you to compare multiple topics at the same time.

This is one of the most powerful analysis tools in the Performance page.

Grouping allows you to answer questions such as:

- How often do callers book appointments vs request a representative?
- Are callers more likely to convert or escalate?
- Is your AI successfully handling common requests, or transferring too often?

### How grouping works

When you create groups using Call Topics, the Performance page splits your data into separate segments. Each group appears as its own line, bar, or chart segment.

This allows direct visual comparison between different types of calls.

Instead of seeing one combined dataset, you see clearly separated performance categories.

---

### Steps to compare topics using groups

1. Go to **Analytics → Performance**
2. Click **Group**
3. Click **Add Group**
4. In the grouping dropdown, select **Call Topic**
5. Choose the topics you want to include
6. Click **Apply**

Each topic will now appear as its own group in charts and analytics.
