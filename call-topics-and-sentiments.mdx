Call topics let Phonely automatically categorize calls by analyzing the full call transcript and selecting the most relevant topic from a predefined list. This provides an additional layer of classification beyond call outcomes and helps teams better understand why calls happened, not just how they ended.

Unlike call outcomes, which are tied to specific blocks in a workflow, Call Topics are transcript-based and evaluated at the end of the call. This makes them flexible and suitable for both high-level categorization and very granular analysis.

## **How Call Topics Work**

You define a list of possible topics that represent common reasons or situations during calls. These can be broad, such as caller transferred or caller asked to speak to a representative, or highly specific, such as caller hung up after agent asked for age.

When a call finishes, Phonely reviews the entire transcript and selects the single topic that best matches what actually occurred during the conversation.

## Viewing Call Topics in Call History

The call history and analytics dashboard provides a centralized view of all calls.

Each call entry includes the duration, call outcome, sentiment, call topic, and timestamp.

To review or edit detected topics:

1. From the sidebar menu find the call section.
2. Click call history
3. Click on any call

This opens the highlights page below.

![Call Tags Call Stats](/assets/call-tags-call-stats.png)

In the highlights tab, under the call stats section you will find 3 sections including sentiments, call ended reasons, duration and call topics.

Under the **call topics** section you can:

- View automatically detected topics
- Select relevant topics
- Unselect irrelevant topics

## Call Topics in the Performance Page

Call topics become most valuable when used inside the **performance page**, where they allow you to isolate, compare, and analyze specific types of conversations. Instead of looking at all calls as a single dataset, call topics let you break down performance based on why customers are calling.

This enables you to answer important operational questions such as:

- How many callers are booking appointments?
- How many callers are requesting callbacks?
- How often callers request a human representative?
- Which types of calls convert successfully?

The performance page provides two primary ways to use call topics:

- **Filtering** - isolate specific conversations
- **Grouping** - compare different types of conversations side-by-side

### Filtering Calls by Topic

Filtering allows you to narrow the performance dashboard to show only calls that match specific topics. All data shown will reflect only calls that match the selected topic.

1. Go to the analytics section and click performance
2. Click the filter button
3. Locate the call topic section
4. Select one or more topics (for example: _appointment booked_)
5. Click apply

### Call Topics in Groups

Groups allow you to compare multiple topics at the same time. This is one of the most powerful analysis tools in the performance page.

When you create groups using call topics, the performance page splits your data into separate segments.This allows direct visual comparison between different types of calls.

1. Go to the analytics section and click performance
2. Click group
3. Click add group
4. In the grouping dropdown, select call topic
5. Choose the topics you want to include
6. Click apply

## Call Topics in Call History

Call history allows you to filter calls based on call topics. This helps you quickly find conversations related to a specific caller intent, such as appointment bookings, support requests, or general inquiries.

To filter calls by topic:

1. Go to call history
2. Click the filter button
3. Locate the call topic section
4. Select one or more topics

## Analytics Fields

Analytics Fields let you define your own structured tags that Phonely's AI extracts from each future call. Use them when call outcomes, topics, and sentiment don't capture what you need to track, such as the reason callers dropped off, the product they asked about, or a numeric observation like the number of times the caller repeated themselves.

Once defined, analytics fields are available for [Performance](/performance) charts (including [pinned charts from Ask AI](/performance#pinned-charts-from-ask-ai)) so you can monitor those values over time.

<Note>
  Analytics fields apply to **future calls only**. They don't backfill historical calls. Plan to wait for new calls to come in before charts based on a new field have data.
</Note>

### Add an Analytics Field

1. From the left sidebar, open the agent and go to **Settings**.
2. Open the **Call Tagging** tab.
3. Find the **Analytics Fields** section and click **Add field**.
4. Enter a **Label** that describes what the field tracks (for example, *Dropoff reason*).
5. Choose a **Type**:
   - **Category** - the AI picks one option per call from your list.
   - **Multi-category** - the AI can pick more than one option per call.
   - **Number** - the AI extracts a numeric value from the call.
6. In the field **Description**, tell the AI exactly what to extract. Be specific - this is the instruction the model follows on every call.
7. For **Category** and **Multi-category** fields, add the options the AI is allowed to choose from. Give each option a clear label and an optional description that explains when it should be selected.
8. Toggle a field or option off to stop using it without deleting your configuration.

Changes save automatically.

### Use Analytics Fields in Performance

After a field is defined and new calls have been processed:

- **Category** and **Multi-category** fields can be used as a dimension when you ask Ask AI to build a chart (for example, *"Calls by dropoff reason for the last 30 days"*).
- **Number** fields can be used as a measure with operations like average, sum, min, max, or percentiles.

See [Pinned charts from Ask AI](/performance#pinned-charts-from-ask-ai) for how to turn a question into a chart that lives in your Performance view.

Analytics fields are not currently exposed as Performance view filter controls. Use the existing filters (status, outcome, topic, end reason, call type, sentiment) to narrow down calls, and use analytics fields as chart dimensions and measures.

### Edit or remove an Analytics Field

All edits happen in **Settings > Call Tagging > Analytics Fields**:

- **Edit** - update the label, description, type, or options. Existing extracted values stay attached to past calls.
- **Disable** - toggle the field off to pause extraction without losing the configuration.
- **Delete** - remove the field entirely. Past calls keep any values that were already extracted, but the field no longer appears in charts and Ask AI.
